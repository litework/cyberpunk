# Changelog

One line per version, newest first. Each version is a commit; rounds of changes are also [tagged releases](https://github.com/litework/cyberpunk/releases). Anything here can be rolled back to.

Numbering: `1.x` is a round of changes agreed in advance; `1.x.y` is a nudge inside that round — one patch number per push, several fixes inside it.

## 1.0

- **1.0** — Public release. The full Cyberpunk 2077 + Phantom Liberty mission tree (363 entries) as a zoomable chart and a sortable table; search, fixer and district filters; done and missed marks in up to three playthroughs; NEXT, READY and LOCKED from the chart's requirement notes; SHARE links, Export / Import, Save image; installable and offline. · [release](https://github.com/litework/cyberpunk/releases/tag/v1.0)
